# Task 2 – Task Manager

## About the Project

A responsive task management application designed to help users organise and track their daily activities.

## Features

- Add new tasks
- Edit and delete tasks
- Mark tasks as completed
- Categorise tasks into Personal, Work and Study
- Set due dates
- Search tasks
- Filter tasks by status
- Dashboard statistics
- Save tasks using Local Storage

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Browser Local Storage
