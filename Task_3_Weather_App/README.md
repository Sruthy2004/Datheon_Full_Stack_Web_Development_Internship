# Task 3 – Weather Forecast Application

## About the Project

A responsive weather application that allows users to search for a city and view its current weather information using the Open-Meteo API.

## Features

- Search weather by city name
- Display current temperature
- Weather condition with icons
- Humidity information
- Wind speed information
- Invalid city error handling
- Loading messages
- Responsive user interface

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Open-Meteo Weather API
