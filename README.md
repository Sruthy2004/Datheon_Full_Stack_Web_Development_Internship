Datheon – Full Stack Web Development Internship

About

This repository contains the projects completed as part of my Datheon Full Stack Web Development Internship.

The projects demonstrate my practical learning and implementation of web development concepts using HTML, CSS, JavaScript, browser storage, and external APIs.

Projects

Task 1 – Personal Developer Portfolio

A responsive personal portfolio website showcasing my profile, technical skills, projects, and contact information.

Technologies: HTML5, CSS3, JavaScript (ES6+)

- "Live Demo" (https://sruthy2004.github.io/datheon-portfolio/)
- "Source Code" (https://github.com/Sruthy2004/datheon-portfolio)

Task 2 – Task Manager

A task management application that helps users organise and track daily activities.

Features:

- Add, edit, and delete tasks
- Mark tasks as completed
- Categorise and search tasks
- Set due dates and filter tasks
- Store tasks using Local Storage

Technologies: HTML5, CSS3, JavaScript (ES6+), Local Storage

- "Live Demo" (https://sruthy2004.github.io/datheon-task-manager/)
- "Source Code" (https://github.com/Sruthy2004/datheon-task-manager)

Task 3 – Weather Forecast Application

A responsive weather application that allows users to search for a city and view current weather information.

Features:

- Search weather by city
- Display temperature and weather conditions
- Show humidity and wind speed
- Handle invalid city searches
- Responsive user interface

Technologies: HTML5, CSS3, JavaScript (ES6+), Open-Meteo API

- "Live Demo" (https://sruthy2004.github.io/datheon-weather-app/)
- "Source Code" (https://github.com/Sruthy2004/datheon-weather-app)

Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Browser Local Storage
- Open-Meteo API
- Git and GitHub
- GitHub Pages
